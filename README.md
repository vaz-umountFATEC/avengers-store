##    Verifique os produtos disponíveis na melhor loja de Action Figure dos Vingadores!

Projeto desenvolvido no 2º semestre do curso Superior de Tecnologia em Segurança da Informação, na disciplina de Programação II, orientada pelo Prof. Lucio Nunes de Lira.

## Funcionalidades
* Autenticação segura com login e senha armazenados em hash SHA-256;
* Criptografia de dados por meio de Cifra de César;
* Gestão de memória permitindo cadastro, remoção, atualização, consulta e validação de memória em dicionário RAM, salvando no arquivo ao encerrar;
* Busca e ordenação, contando com listagem alfabética automática (Insertion Sort até 100 produtos; Merge Sort acima disso) e busca por ID ou nome (Linear e Binária).

## Primeira execução
1. Tenha o Python 3 instalados e mantenha todos os arquivos .py na mesma página.
2. Se houver um login.txt preenchido, esvazie-o para simular o primeiro uso.
3. No terminal, dentro da pasta do projeto, execute:
        `python main.py`
4. Cadastre usuário e senha iniciais e faça login - `inventario.csv` será criado automaticamente.
5. Para salvar e criptografar as alterações no arquivo, encere o programa pela opção '0- Salvar e Sair'
